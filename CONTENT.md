# Как добавлять материалы в PetroLearn

Весь контент сайта лежит в четырёх файлах данных. Разметку и код трогать
не нужно — достаточно дописать объект в нужный массив.

| Файл | Что внутри |
|---|---|
| `theory_data.js` | Разделы теории и их темы |
| `formulas_data.js` | Справочник формул |
| `site_data.js` | Глоссарий и вопросы базового теста / теста инженера |
| `gdis_quiz_data.js` | Вопросы теста по ГДИС |

После любой правки запустите проверку — она ловит битые ссылки,
несуществующие формулы, ошибки в ключах ответов и опечатки в типах блоков:

```bash
node tests/validate-data.js     # быстро, без браузера
node tests/smoke.js             # полный прогон страниц (нужен playwright)
```

Обе проверки запускаются автоматически при каждом push.

## Перекрёстные ссылки

Внутри любого текста можно сослаться на формулу или термин глоссария.
Ссылка превращается в кликабельную, а у термина появляется всплывающая
подсказка с определением.

```
{{formula:dupuit}}                        → ссылка с id формулы
{{formula:dupuit|формула Дюпюи}}          → ссылка со своей подписью
{{term:Скин-фактор}}                      → ссылка на термин глоссария
{{term:Скин-фактор|скин-фактором}}        → то же, но в нужном падеже
```

Валидатор проверяет, что каждая такая ссылка ведёт на существующую цель.
Если формулы с таким id нет — сборка упадёт с понятным сообщением.

## Теория

Раздел — это страница. Тема — заголовок внутри страницы. Тема состоит
из блоков.

```js
{
    id: 'wells',                     // латиницей, без пробелов
    page: 'theory-wells.html',       // существующий файл
    title: 'Скважины и режимы работы залежи',
    description: 'Короткое описание для карточки на странице «Теория»',
    topics: [
        {
            id: 'inflow',            // уникален по всему сайту — это якорь в URL
            title: 'Приток к скважине',
            blocks: [ /* см. ниже */ ]
        }
    ]
}
```

### Типы блоков

**`text`** — абзацы. Разделяются двойным переносом `\n\n`.
Поддерживает перекрёстные ссылки.

```js
{ type: 'text', text: 'Первый абзац.\n\nВторой абзац с {{term:Пористость}}.' }
```

**`formula`** — встроенная карточка формулы из справочника.

```js
{ type: 'formula', ref: 'dupuit' }
```

**`table`** — таблица. Число ячеек в каждой строке должно совпадать
с числом колонок в шапке (валидатор это проверяет).

```js
{
    type: 'table',
    caption: 'Типичные значения пористости',
    head: ['Коллектор', 'Пористость, д.ед.'],
    rows: [
        ['Песчаник', '0,15–0,25'],
        ['Известняк', '0,05–0,15']
    ]
}
```

**`note`** — выделенная сноска на акцентном фоне.

```js
{ type: 'note', text: 'В реальных залежах режимы почти всегда смешанные.' }
```

**`list`** — маркированный или нумерованный список.

```js
{ type: 'list', ordered: false, items: ['Первый пункт', 'Второй с {{formula:vogel}}'] }
```

**`image`** — иллюстрация с подписью. Файл кладётся в `assets/`.
Валидатор проверяет, что файл существует.

```js
{
    type: 'image',
    src: 'assets/well-scheme.png',
    alt: 'Схема конструкции скважины',   // обязателен для доступности
    caption: 'Конструкция эксплуатационной скважины'
}
```

**`example`** — разобранный пример расчёта. Самый ценный формат:
«дано → решение по шагам → ответ». В шагах можно смешивать текст и формулы.

```js
{
    type: 'example',
    title: 'Пример: дебит вертикальной скважины по Дюпюи',
    ref: 'dupuit',                       // ссылка на формулу в справочнике
    given: 'k = 120 мД; h = 12 м; ΔP = 4 МПа; μ = 2,5 мПа·с',
    steps: [
        { text: 'Приводим величины к СИ.' },
        {
            text: 'Считаем логарифмический член:',
            latex: '\\ln\\dfrac{R_к}{r_с} = \\ln 2500 \\approx 7{,}824'
        },
        'Шаг можно задать и просто строкой, без формулы.'
    ],
    result: 'Q ≈ 158 м³/сут'
}
```

**`reference`** — список литературы к теме.

```js
{
    type: 'reference',
    items: [
        'Щелкачев В.Н. Основы подземной гидравлики',
        { text: 'SPE 1476, Vogel J.V.', href: 'https://doi.org/...' }
    ]
}
```

## Формулы

```js
{
    id: 'dupuit',                        // латиницей; на него ссылаются {{formula:…}}
    category: 'inflow',                  // id из formulaCategories
    title: 'Формула Дюпюи',
    latex: 'Q = \\dfrac{2\\pi k h \\Delta P}{\\mu \\ln(R_к/r_с)}',
    variables: [
        { symbol: 'Q', name: 'дебит скважины', units: 'м³/сут' },
        { symbol: 'k', name: 'проницаемость пласта', units: 'мД' }
    ],
    note: 'Действует при установившейся плоскорадиальной фильтрации.',
    source: 'Dupuit J. (1863); Басниев К.С. Подземная гидромеханика',
    calcLink: { href: 'calculators.html#calc-card-darcy', label: 'Посчитать' }  // необязательно
}
```

`source` формально необязателен, но валидатор о нём предупредит: атрибуция —
то, что отличает справочник от случайной подборки формул.

Внутри `latex` обратные слэши удваиваются: `\\dfrac`, а не `\dfrac`.

## Глоссарий

```js
{ term: 'Скин-фактор', definition: 'Безразмерная величина, характеризующая…' }
```

Термины сортируются автоматически, дубликаты валидатор отклонит.

## Вопросы тестов

Три типа. Порядок вопросов и вариантов ответа перемешивается при каждом
прохождении — ключ ответа пересчитывается автоматически.

**`single`** — один правильный вариант, `answer` — индекс с нуля.

```js
{ id: 1, type: 'single', question: 'Вопрос? (выберите один)',
  options: ['Первый', 'Второй'], answer: 1 }
```

**`multi`** — несколько правильных, `answer` — массив индексов.
Если в тексте написано «(выберите три)», в ключе должно быть ровно три
индекса — валидатор сверяет это.

```js
{ id: 2, type: 'multi', question: 'Вопрос? (выберите два)',
  options: ['А', 'Б', 'В'], answer: [0, 2] }
```

**`matrix`** — таблица, по одной отметке на строку. Ключ задаётся
**названиями**, а не индексами, поэтому от порядка не зависит.

```js
{
    id: 25, type: 'matrix',
    question: 'Что означают отрезки на графике?',
    image: 'assets/gdis-diagnostic-plot.png',   // необязательно
    imageAlt: 'Билогарифмический график',
    rows: ['Линия 1', 'Линия 2'],
    columns: ['ВСС', 'Радиальный режим'],
    answer: { 'Линия 1': 'ВСС', 'Линия 2': 'Радиальный режим' }
}
```

### Необязательные поля вопроса

`image`, `imageAlt`, `explanation`, `source` — сохраняются и доходят
до экрана у всех типов вопросов.

Если ключ ответа пока неизвестен, поставьте `answer: null`: вопрос будет
показываться, но не участвовать в подсчёте баллов, а на экране результатов
появится нейтральное сообщение вместо «0 из N». Валидатор выдаст
предупреждение, но не ошибку.

## Чек-лист перед коммитом

1. `node tests/validate-data.js` — зелёный
2. `node tests/smoke.js` — зелёный
3. Новые изображения лежат в `assets/` и имеют `alt`
4. У новых формул заполнен `source`
5. Все `{{formula:…}}` и `{{term:…}}` ведут на существующие цели
   (проверяется автоматически)
