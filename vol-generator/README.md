# VOL Generator

Веб-инструмент для конвертации добычи (выгрузка из Access) в формат `.vol` для Petrel. Работает полностью в браузере, без сервера — данные не покидают компьютер.

## Запуск

Открыть `index.html` в браузере (двойной клик, либо через любой локальный веб-сервер, например `python3 -m http.server`). Интернет не нужен — библиотека для чтения Excel лежит в `vendor/`.

## Как пользоваться

1. **Загрузить файл** — Excel-выгрузка из Access (лист с колонками вида `UNIQUEID, DATE, DAYS, OIL, WATER, GAS, ...`).
2. **Сопоставить колонки** — колонки подставляются автоматически по названию, при необходимости поправить вручную. Если скважина и объект закодированы в одной колонке (`UVN_1:PT_1`), оставить галочку "объединённый идентификатор".
3. **Указать плотность** — для каждого объекта, найденного в файле, ввести плотность нефти (т/м³). Нефть переводится из тонн в м³ по формуле `Объём = Масса / Плотность`; вода, газ и закачка используются как есть.
4. **Проверить превью и скачать** `.vol`.

## Формат идентификатора скважины

`UVN_1:PT_1` → скважина `1`, объект `PT_1` (часть после последнего `_` до `:` — номер скважины, часть после `:` — объект).

## Правило свода суток (DAYS)

Если у скважины несколько объектов, за месяц суммируются объёмы (нефть/вода/газ/закачка), а для DAYS выбирается правило — максимум или сумма по объектам (переключатель на шаге 3). По умолчанию — максимум, так как физически скважина не может работать больше календарных суток месяца.

## Формат .vol

Проверено побайтово на реальном экспорте Petrel: табуляция как разделитель, CRLF-переносы строк, шапка `*METRIC` / `*DATE *OIL *WATER *GAS *WINJ *DAYS *BHP`, далее блоки `*NAME <скважина>` со строками `дата(дд.мм.гггг) OIL WATER GAS WINJ DAYS BHP`. `*OIL` и остальные объёмные колонки — суммарный объём **за месяц**, Petrel сам делит на календарные дни для получения суточного дебита и на DAYS/календарные_дни — для коэффициента эксплуатации.
